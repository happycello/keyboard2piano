# keyboard2piano · 键间

把电脑键盘变成随手可弹的乐器。提供完整半音阶映射与数字简谱两种演奏模式，支持和弦、八度切换和模拟踏板。

纯 HTML、CSS 与 JavaScript 实现，无需安装依赖，不加载远程音源，下载后可以离线运行。

## 开始演奏

下载项目，使用现代桌面浏览器打开 `index.html`，点击 **开启声音**。建议使用 Edge 或 Chrome，切换到英文输入法。

### 模式一：主键盘半音阶

默认从 C2 开始，按以下物理键位顺序连续排列 45 个半音，覆盖 C2–G♯5：

1. Z 行：Z 到 /
2. A 行：A 到 '
3. Q 行：Q 到 ]
4. 数字行：1 到 =

界面显示每个键对应的音名。标点按物理键位识别，无需按 Shift。

### 模式二：数字简谱

主键盘上方数字行与右侧数字小键盘均可使用，也支持混合演奏。

| 按键 | 功能 |
| --- | --- |
| 1、2、3、4、5、6、7 | do、re、mi、fa、sol、la、si |
| ↑ | 升八度 |
| ↓ | 降八度 |
| ← | 降半音 |
| → | 升半音 |

默认 do 为中央 C（C4），起始八度可调。方向键按住生效、松开恢复；可以先按方向键，也可以在按住音符时改变音高。上下相抵、左右相抵，八度与半音可以组合。右侧小键盘建议开启 Num Lock。

### 踏板与控制

| 按键 | 功能 |
| --- | --- |
| Ctrl | 弱音：降低整体音量 |
| Fn / Shift | 柔音：柔化音色，并减轻新音起音 |
| 空格 | 延音：松开发音键后保留余音 |
| Esc | 全部止音 |

踏板也可点击按钮锁定，再次点击解除。切换窗口、隐藏页面、切换模式或音域时自动止音。

## 当前限制

- 当前音色为本地合成，并非真实钢琴采样；踏板为电子模拟。
- 普通电脑键盘不提供力度信息，同时可识别的按键数量取决于键盘硬件。
- Fn 常由硬件处理，无法识别时请用 Shift。
- 浏览器或系统保留的组合快捷键可能中断演奏。
- 当前主要面向桌面键盘使用，尚未完成各浏览器和设备的完整兼容性验证。

## 项目文件

- `index.html`：演奏页面
- `style.css`：界面样式
- `app.js`：按键映射、音频合成与交互
- `check.cjs`：核心逻辑检查（使用模拟音频与页面环境，不替代实际试听）
- `使用说明.md`：中文使用说明

## 开发检查

安装 Node.js 后运行：

```sh
node --check app.js
node check.cjs
```

检查涵盖双数字键盘映射、混合和弦、独立松键、方向键组合、延音释放及止音重置。

## GitHub Pages

将项目文件直接放在仓库根目录。在 GitHub 仓库的 **Settings → Pages** 中选择 **Deploy from a branch**，选择存放这些文件的分支与 **/ (root)**，保存后等待发布。发布后的地址会显示在 Pages 设置中。
